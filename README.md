# 우아홈

우아홈 프로젝트와 총괄 에이전트 운영 지침을 관리하는 저장소입니다.

## 현재 상태

- 저장소 생성과 에이전트 기본 운영 지침 준비 단계입니다.
- 서비스 코드, 기술 스택, 빌드·테스트·CI는 아직 없습니다.
- 이 문서만으로 에이전트가 자동 또는 상시 실행되지는 않습니다.

## 쉽게 시작하기

이 저장소를 작업 환경에서 연 뒤 에이전트에게 다음과 같이 요청하세요.

> AGENTS.md를 읽고 우아홈 총괄 역할을 맡아줘. 내 요청을 독립 작업으로 나누고 서브에이전트에게 병렬 배정한 뒤 결과를 검토하고 통합해줘.

처음에는 우아홈이 어떤 서비스인지와 가장 먼저 만들 기능을 알려주세요. 총괄은 이를 바탕으로 작업을 정리합니다. 서브에이전트 실행을 지원하는 환경이 필요하며, 지원하지 않으면 순차 수행 여부를 알립니다.

## 파일 안내

- `AGENTS.md`: 총괄과 서브에이전트의 역할, 병렬 작업 규칙, 완료 기준
- `tasks/template.yaml`: 작업별 담당자·수정 경로·의존성·검증 기록 양식

## 작업 흐름

요청 확인 → 요구사항과 저장소 조사 → 작업 배정 → 독립 작업 병렬 수행 → 결과 검토·통합 → 필요한 검증 → 결과 보고
