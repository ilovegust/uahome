# 우아홈 구현 범위와 연결 계획

## 첫 버전

1688 후보 CRUD, 수입 견적 총액의 개당 배분과 부가세 현금·원가 구분, 로켓그로스 입출고·배송·보관비를 반영한 마진·목표 판매가, 수동 점수 기반 후보 정렬, 발주 검토서, 상품등록 초안·공통 CSV, 쿠팡 상품 ID·SKU·센터 입고계획·운송장과 입고 단계 수동 추적, 실제 고객 리뷰와 답변 초안, 항목별 승인, 외부 수동 완료 기록, 변경 기록, SQLite 영구 저장과 JSON 백업·복원.

`검토할 작업 준비`는 미작성 리뷰 초안과 현재 단계에서 가능한 사입·등록 요청을 일괄 생성합니다. 중복 검토 요청은 만들지 않으며 누락 항목은 이유와 함께 건너뜁니다. 주문·결제·게시·답변은 실행하지 않습니다.

## 판매처·사입처 확인 후 진행

| 연결 | 필요한 정보 | 다음 구현 |
| --- | --- | --- |
| 상품 선정 | 카테고리·예산·목표 마진·조사 가능한 데이터 | 공식 제공 데이터/CSV 수집, 근거·조회 시각 저장 |
| 사입처 | 국내 도매/해외 공급처, 발주 방식, 통화, MOQ | 공급처별 견적 수집과 발주 서식, 공식 API 지원 시 승인 후 주문 |
| 판매처 | 스마트스토어/쿠팡/기타, 판매자 계정의 API 권한 | 실제 등록 양식·필수 속성 검증, 승인 후 공식 API 등록 |
| 리뷰 | 판매처별 실제 리뷰 데이터와 API 제공 범위 | 리뷰 동기화·중복 방지, 사람 검토 후 공식 지원 경로로 답변 |
| 문구 생성 | 사용할 모델과 서버 비밀키 연결 | 입력 근거만 사용한 문구 생성과 생성 이력, 승인 분리 |
| 서버 운영 | 운영 위치와 사용자 수 | 로그인·사용자별 권한·HTTPS·영구 DB·백업·배포 |

외부 작업은 요청 ID·결과 영수증·재시도 규칙을 도입한 뒤 실행합니다. 현재 `completed`는 사용자가 외부에서 처리했다고 기록한 상태이며 API 성공 증거가 아닙니다.

## 데이터와 권한 원칙

실제 고객 리뷰만 사용하고 리뷰·별점은 만들어 게시하지 않습니다. 고객 개인정보와 API 키는 공개 저장소에 보관하지 않습니다. 공급처 URL은 참고 링크로만 저장하며 서버가 임의 URL을 가져오지 않습니다. 외부 API는 공식 제공 범위와 판매자 계정 권한을 확인해 연결합니다.

## 배포 상태

현재 GitHub에서 내려받아 실행하는 로컬 앱입니다. 이번 작업 환경에는 Sites의 필수 설정·빌드·소스 동기화 실행 파일이 없어 온라인 배포는 수행하지 않았습니다. 화면의 브라우저 직접 조작 검증도 도구 부재로 미실시이며 HTTP·도메인·저장소 자동 검사를 제공합니다.
