# 다음 연결 단계 — 현재 판매자 등록 완료

현재 확인한 운영 방식은 **1688 사입 → 쿠팡 로켓그로스 판매**입니다. 쿠팡 판매자 등록은 완료했고 Open API는 아직 발급 전입니다.

## 오늘 시작할 수 있는 것

1. 앱에 1688 상품 URL 하나와 옵션·단가·MOQ·수량을 입력합니다.
2. 배송/통관 대행사의 견적을 받아 수입원가 계산기에 입력합니다.
3. WING에서 상품의 실제 예상 수수료·그로스 비용을 확인하고 마진을 계산합니다.
4. 사입 검토서와 등록 초안을 준비하고 승인함에서 검토합니다.
5. 실제 주문·등록·센터 입고는 각각 해당 서비스에서 처리하고 앱에 완료 상태와 식별자를 기록합니다.

## 실제 상품등록을 연결하려면

1. 쿠팡 WING에서 공식 Open API 발급 안내를 확인합니다. 메뉴 위치·발급 조건은 계정에서 현재 안내를 따르세요.
2. 로켓그로스 상품 생성 API 이용·검수 기준 동의가 필요한지 확인하고 진행합니다.
3. 준비한 뒤에는 **“Open API 발급 완료”**라고만 알려주세요. Access Key·Secret Key는 채팅이나 GitHub에 붙이지 않습니다.
4. 다음 개발 단계에서 서버 비밀값 저장 위치를 먼저 마련하고, 계정 권한·상품 카테고리·필수 고시·이미지·바코드·옵션을 확인한 뒤 등록 연동을 구현합니다.

현재 앱은 API 키를 입력받거나 저장하지 않습니다. 키를 발급받는 것만으로 지금 버전의 외부 등록이 자동 활성화되지는 않습니다. 연결 코드와 인증된 운영 환경을 추가해야 합니다.

공식 문서와 확인한 지원 범위는 [1688·로켓그로스 연결 안내](coupang-1688.md)를 참고하세요. 상품평 리뷰 기능은 고객 Q&A와 다르며, 공개 API 지원 여부를 확인하기 전에는 자동 전송을 약속하지 않습니다.
